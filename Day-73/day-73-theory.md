# 1. Define a Retriever.
A Retriever is a component in a RAG system that searches a knowledge base and retrieves the most relevant documents or text chunks for a user's query. 

The retrieved information is then passed to the Large Language Model (LLM) to generate the final answer.  

# 2. Differentiate Sparse Retrieval and Dense Retrieval. 

| **Sparse Retrieval** | **Dense Retrieval** |
|----------------------|---------------------|
| Uses keyword-based matching. | Uses semantic (meaning-based) matching. |
| Represents documents as sparse vectors (e.g., TF-IDF, BM25). | Represents documents as dense embeddings generated by neural networks. |
| Matches exact or similar words. | Matches similar meanings even if different words are used. |
| Fast and computationally inexpensive. | More computationally intensive. |
| Example: BM25 | Example: DPR, Sentence Transformers, OpenAI Embeddings |

# 3. Explain BM25. 

BM25 (Best Matching 25) is an improved keyword-based retrieval algorithm. 

It ranks documents based on: 
- Keyword frequency 
- Document length 
- Word importance 

# 4. What is Hybrid Search? 

Hybrid Search combines Sparse Retrieval (e.g., BM25) and Dense Retrieval (embedding-based search) to improve search performance.

It leverages:
- Keyword matching from sparse retrieval.
- Semantic understanding from dense retrieval.

**Benefits:**
- Finds documents containing exact keywords.
- Retrieves semantically similar documents even when different words are used.
- Improves overall search accuracy and relevance.

# 5. Why are retrievers important in RAG? 
- Reduces hallucinations by grounding responses in retrieved documents.
- Provides access to up-to-date and domain-specific information.
- Improves answer accuracy and reliability.
- Extends the model's knowledge beyond its training data.
- Produces more relevant and context-aware responses.
