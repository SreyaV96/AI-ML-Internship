# 1. Define Conversation Memory.
Conversation memory is a feature that allows a chatbot to remember information shared earlier in a conversation. It uses this information to give relevant and meaningful responses instead of treating every message as a new one.

# 2. Explain why memory is important in AI chatbots.
Memory is important because it helps the chatbot understand the context of the conversation. It can remember details like the user's name, location, or previous questions, making the conversation smoother, more natural, and personalized.
# 3. Explain the workflow of a chatbot with memory.
The chatbot first receives the user's message and saves it in its conversation memory. Then it checks previous messages to understand the context. Based on both the current message and the stored information, it generates a suitable response. Finally, it saves the new response in memory so it can be used later in the conversation.

# 4. List five advantages of conversation memory.
1. It remembers previous conversations.
2. It provides personalized responses.
3. It keeps the conversation connected and meaningful.
4. It reduces repeated questions.
5. It improves the overall user experience.

# 5. Differentiate between chatbots with and without memory.

| Chatbot with Memory | Chatbot without Memory |
|---------------------|------------------------|
| Remembers previous messages. | Does not remember previous messages. |
| Understands the conversation context. | Treats every message as a new conversation. |
| Gives personalized answers. | Gives general answers. |
| Suitable for long conversations. | Better for short conversations only. |
| Provides a better user experience. | Less interactive and less natural. |
