# 1. Define an AI chatbot.
An AI chatbot is a chatbot that uses artificial intelligence (AI), natural language processing (NLP), and machine learning (ML) to understand user messages and provide human-like responses. It can learn from data and handle a wide range of conversations.

# 2. Explain intent classification.
Intent classification is the process of identifying the purpose or goal behind a user's message. It helps the chatbot determine what the user wants and select the most appropriate response. 

### Example
User: 
Where is my order? 
Intent: 
Track Order 

# 3. Why is training data important?
Training data is important because it teaches an AI chatbot how to understand language, recognize user intents, identify patterns, and generate accurate responses. High-quality and diverse training data improves the chatbot's accuracy and performance.

## 4. What is feature extraction?
Feature extraction is the process of converting raw text into numerical representations that machine learning models can understand. Examples include Bag of Words (BoW), TF-IDF, Word Embeddings 

## 5. Compare rule-based and AI chatbots.

| Rule-Based Chatbot | AI Chatbot |
|--------------------|------------|
| Uses predefined rules  | Uses AI, NLP, and machine learning. |
| Responds only to programmed commands. | Understands natural language and context. |
| Cannot learn from interactions. | Can improve through training and data. |
| Best for simple, repetitive tasks like FAQs | Suitable for complex and dynamic conversations. |
| Less flexible. | More flexible and intelligent. |
