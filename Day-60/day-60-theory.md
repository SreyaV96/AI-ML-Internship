# 1. Define a Menu-Driven Chatbot.
A Menu-Driven Chatbot is a chatbot that interacts with users by displaying a list of predefined options (a menu). The user selects an option, and the chatbot provides the corresponding response. It is one of the simplest types of chatbots and is commonly used for customer support, college enquiries, banking services, and FAQs. 
# 2. Explain how it works.
- The chatbot displays a menu of options.
- The user selects an option by entering a number or keyword.
- The chatbot processes the user's choice.
- It displays the corresponding information.
- The chatbot asks whether the user wants to continue or exit.
- If the user chooses to continue, the menu is displayed again; otherwise, the chatbot exits. 
# 3. List five advantages. 
- Beginner-friendly 
- Easy to build 
- Fast response 
- Suitable for FAQs 
- No AI training required 
# 4. List four limitations. 
- Users must choose from the menu. 
- Cannot answer unexpected questions. 
- No understanding of natural language. 
- No learning capability. 
# 5. Compare Menu-Driven and Rule-Based Chatbots. 
# Rule-Based Chatbot vs Menu-Driven Chatbot

| Rule-Based Chatbot | Menu-Driven Chatbot |
|--------------------|---------------------|
| User types questions | User selects options |
| May have spelling issues | No spelling issues |
| Uses text matching | Uses menu selection |
| More flexible | Easier for beginners |
| Better for simple conversations | Better for structured information |
